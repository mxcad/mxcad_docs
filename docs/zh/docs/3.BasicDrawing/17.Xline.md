# 构造线

我们可以通过实例化一个 McDbXline() 对象创建构造线。构造线是从基点出发、沿指定方向双向无限延伸的直线，常用于辅助绘图和定位参考。通过设置 McDbXline() 实例对象的基点 basePoint 与方向向量 unitDir 绘制构造线，也可以直接调用 setBasePoint(x, y, z) 与 setUnitDir(x, y, z) 方法分别设置基点与方向向量，还能根据自身需求设置构造线颜色 trueColor 、所在图层 layer 、线性比例 linetypeScale 等多种属性。

构造线继承自 McDbCurve，因此还可以像曲线一样调用 getPointAtDist() 取线上指定距离处的点、getFirstDeriv() 取方向导数等曲线方法。

点击 [McDbXline()](../../api/classes/2d.McDbXline.md) 查看详细属性和方法说明。

```ts
import { MxCpp, McCmColor, McDbXline, McGePoint3d, McGeVector3d } from "mxcad"

const mxcad = MxCpp.getCurrentMxCAD()

// 通过属性设置基点与方向向量
const xline = new McDbXline()
xline.basePoint = new McGePoint3d(0, 0, 0)
xline.unitDir = new McGeVector3d(1, 1, 0)
xline.trueColor = new McCmColor(255, 0, 0)
mxcad.drawEntity(xline)

// 通过方法设置基点与方向向量
const xline_1 = new McDbXline()
xline_1.setBasePoint(100, 0, 0)
xline_1.setUnitDir(1, 0, 0)
xline_1.trueColor = new McCmColor(0, 255, 0)
mxcad.drawEntity(xline_1)
```

:::demo
```tsx
import {  McObject, McDbXline, McGePoint3d, McGeVector3d, McCmColor } from "mxcad"

export default () => {
    const mxcad = new McObject()
    mxcad.create({
      canvas: "#myCanvas",
      locateFile: (fileName: string)=> {
            // CDN 加载必须使用wasm/2d-st中的资源、因为github的限制无法使用wasm/2d 资源
            // 需要使用wasm/2d需要遵循浏览器同源策略或使用其他手段规避浏览器同源策略
            return self.location.origin + "/mxcad_docs/wasm/2d-st/" + fileName
      },
      // 加载字体的目录位置
      fontspath: self.location.origin + "/mxcad_docs/fonts",
      // 加载转换后的图纸文件
      fileUrl: self.location.origin + "/mxcad_docs/test.mxweb",
      onOpenFileComplete: ()=>{
            // 沿 45 度方向双向无限延伸的构造线
            const xline = new McDbXline()
            xline.basePoint = new McGePoint3d(0, 0, 0)
            xline.unitDir = new McGeVector3d(1, 1, 0)
            xline.trueColor = new McCmColor(255, 0, 0)
            mxcad.drawEntity(xline)

            // 沿 X 轴方向的水平构造线
            const xline_1 = new McDbXline()
            xline_1.setBasePoint(0, 200, 0)
            xline_1.setUnitDir(1, 0, 0)
            xline_1.trueColor = new McCmColor(0, 255, 0)
            mxcad.drawEntity(xline_1)

            // 沿 Y 轴方向的垂直构造线
            const xline_2 = new McDbXline()
            xline_2.setBasePoint(200, 0, 0)
            xline_2.setUnitDir(0, 1, 0)
            xline_2.trueColor = new McCmColor(0, 0, 255)
            mxcad.drawEntity(xline_2)

            mxcad.zoomAll()
            mxcad.zoomScale(0.8)
      }
    })
    return (<div style="height: 500px; overflow: hidden;"><canvas id="myCanvas" ></canvas>
    </div>)
}
```
