# 射线

我们可以通过实例化一个 McDbRay() 对象创建射线。射线是从基点开始、沿指定方向无限延伸的直线，常用于辅助定位、测量和构造几何关系。通过设置 McDbRay() 实例对象的基点 basePoint 与方向向量 unitDir 绘制射线，也可以直接调用 setBasePoint(x, y, z) 与 setUnitDir(x, y, z) 方法分别设置基点与方向向量，还能根据自身需求设置射线颜色 trueColor 、所在图层 layer 、线性比例 linetypeScale 等多种属性。

点击 [McDbRay()](../../api/classes/2d.McDbRay.md) 查看详细属性和方法说明。

```ts
import { MxCpp, McCmColor, McDbRay, McGePoint3d, McGeVector3d } from "mxcad"

const mxcad = MxCpp.getCurrentMxCAD()

// 通过属性设置基点与方向向量
const ray = new McDbRay()
ray.basePoint = new McGePoint3d(0, 0, 0)
ray.unitDir = new McGeVector3d(1, 0, 0)
ray.trueColor = new McCmColor(255, 0, 0)
mxcad.drawEntity(ray)

// 通过方法设置基点与方向向量
const ray_1 = new McDbRay()
ray_1.setBasePoint(100, 100, 0)
ray_1.setUnitDir(1, 1, 0)
ray_1.trueColor = new McCmColor(0, 255, 0)
mxcad.drawEntity(ray_1)
```

:::demo
```tsx
import {  McObject, McDbRay, McGePoint3d, McGeVector3d, McCmColor } from "mxcad"

export default () => {
    const mxcad = new McObject()
    mxcad.create({
      canvas: "#myCanvas",
      locateFile: (fileName: string)=> {
            // CDN 加载必须使用wasm/2d-st中的资源、因为github的限制无法使用wasm/2d 资源
            // 需要使用wasm/2d需要遵循浏览器同源策略或使用其他手段规避浏览器同源策略
            return self.location.origin + "/mxcad_docs/wasm/2d-st/" + fileName
      },
      // 加载字体的目录位置
      fontspath: self.location.origin + "/mxcad_docs/fonts",
      // 加载转换后的图纸文件
      fileUrl: self.location.origin + "/mxcad_docs/test.mxweb",
      onOpenFileComplete: ()=>{
            // 沿 X 轴正方向的水平射线
            const ray = new McDbRay()
            ray.basePoint = new McGePoint3d(0, 0, 0)
            ray.unitDir = new McGeVector3d(1, 0, 0)
            ray.trueColor = new McCmColor(255, 0, 0)
            mxcad.drawEntity(ray)

            // 沿 45 度方向延伸的射线
            const ray_1 = new McDbRay()
            ray_1.setBasePoint(0, 0, 0)
            ray_1.setUnitDir(1, 1, 0)
            ray_1.trueColor = new McCmColor(0, 255, 0)
            mxcad.drawEntity(ray_1)

            // 沿 Y 轴负方向延伸的射线
            const ray_2 = new McDbRay()
            ray_2.setBasePoint(0, 0, 0)
            ray_2.setUnitDir(0, -1, 0)
            ray_2.trueColor = new McCmColor(0, 0, 255)
            mxcad.drawEntity(ray_2)

            mxcad.zoomAll()
            mxcad.zoomScale(0.8)
      }
    })
    return (<div style="height: 500px; overflow: hidden;"><canvas id="myCanvas" ></canvas>
    </div>)
}
```
