# Class: McGePoint3d

[2d](../modules/2d.md).McGePoint3d

McGePoint3d 表示三维空间中的一个点对象。

**`Description`**

该类用于描述和操作 CAD/三维场景中的坐标点，常见用途包括：
计算两点距离、执行点与向量的运算、进行坐标变换以及与 Three.js 的向量对象互转。
它是很多几何运算和图形绘制逻辑的基础类型。

**`Example`**

```ts
import { McGePoint3d, McGeVector3d, McGeMatrix3d } from "mxcad";

const pt1 = new McGePoint3d(10, 20, 0);
const pt2 = new McGePoint3d(30, 40, 0);

const distance = pt1.distanceTo(pt2);
console.log("距离：", distance);

const vec = pt2.sub(pt1);
const matrix = new McGeMatrix3d();
matrix.setToTranslation(vec);//平移矩阵
pt1.transformBy(matrix);//应用平移矩阵
```
