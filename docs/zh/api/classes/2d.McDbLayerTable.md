# Class: McDbLayerTable

[2d](../modules/2d.md).McDbLayerTable

McDbLayerTable 是数据库中的图层表，负责管理当前图纸中的所有图层记录。

**`Description`**

该类用于管理 CAD 图层的集合，便于查询、添加、判断和访问图层对象。
通过它可以完成：
- 获取图层表中所有图层记录 ID；
- 向图层表中新增图层；
- 按名称查找某个图层；
- 判断某个图层是否存在；
- 后续通过 McObjectId 获取真正的 McDbLayerTableRecord 进行属性编辑。

使用方式：
1. 先通过数据库对象获取当前图层表；
2. 调用 getAllRecordId() 获取所有图层 ID；
3. 使用 add() / get() / has() 管理图层；
4. 对返回的图层记录继续设置颜色、状态、线宽等属性。

总结：在实际开发中，McDbLayerTable 主要用于统一管理图层资源，是图层增删查改和图层状态控制的核心入口。

**`Example`**

```ts
import { MxCpp, McDbLayerTable } from "mxcad";

// 创建图层表并向其中添加图层记录。
async function testLayerTable() {
  const mxcad = MxCpp.getCurrentMxCAD();
  const layerTable: McDbLayerTable = mxcad.getDatabase().getLayerTable();

  const aryId = layerTable.getAllRecordId();
  console.log("图层数量:", aryId.length);

  aryId.forEach((id) => {
    const layerRec = id.getMcDbLayerTableRecord();
    if (!layerRec) return;
    console.log("图层名:", layerRec.name);
  });

  const exists = layerTable.has("测试图层");
  console.log("是否存在测试图层:", exists);
}
```
