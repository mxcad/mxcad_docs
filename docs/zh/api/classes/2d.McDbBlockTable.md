# Class: McDbBlockTable

[2d](../modules/2d.md).McDbBlockTable

McDbBlockTable 是数据库中的块表，负责管理当前图纸中的所有块定义。

**`Description`**

该类用于维护和访问图纸中的块定义集合，包括遍历、添加、查找和判断块记录是否存在。
通过它可以完成：
- 获取全部块记录 ID；
- 新增命名块定义；
- 按名称查找块记录；
- 判断块是否存在；
- 为后续块插入和块引用提供入口。

使用方式：
1. 通过数据库获取块表 `MxCpp.getCurrentMxCAD().getBlockTable()`；
2. 调用 getAllRecordId() 查看全部块表记录对象；
3. 使用 add() / get() / has() 管理块定义；
4. 从返回的 McObjectId 中获取 McDbBlockTableRecord 继续编辑块内容。

总结：在实际开发中，McDbBlockTable 是块管理的核心入口，适合创建和检索图块定义，支撑块插入和动态块开发。

**`Example`**

```ts
//遍历图纸中的所有图块
import { MxCpp, McDbBlockTable } from "mxcad"

// 获取当前cad对象
let mxcad = MxCpp.getCurrentMxCAD();
// 获取块表对象
let blockTable: McDbBlockTable = mxcad.getDatabase().getBlockTable();
// 获取块表中的所有记录对象id
let aryId = blockTable.getAllRecordId();
//遍历记录对象id，获取块表记录对象详情
aryId.forEach((id) => {
let blkRec = id.getMcDbBlockTableRecord();
if (blkRec === null) return;
    console.log(blkRec);
    console.log("blkRec.name:" + blkRec.name);
    console.log("blkRec.origin:" + blkRec.origin);
});
```
