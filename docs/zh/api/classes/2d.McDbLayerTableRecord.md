# Class: McDbLayerTableRecord

[2d](../modules/2d.md).McDbLayerTableRecord

McDbLayerTableRecord 是图层表中的单条记录，用于保存和管理图层的属性。

**`Description`**

该类用于描述一张图层，包括图层名、颜色、线型、锁定状态、冻结状态和是否关闭等。
通过它可以完成：
- 新建和命名图层；
- 设置图层颜色、线宽、线型和可打印性；
- 控制图层是否被冻结、锁定或关闭；
- 将图层对象添加到图层表中并用于后续实体归属。

使用方式：
1. 创建 McDbLayerTableRecord 实例；
2. 设置 name / color / lineWeight / isLocked 等属性；
3. 插入到图层表中；
4. 使用其对象 ID 为实体指定图层。

总结：在实际开发中，McDbLayerTableRecord 是图层属性控制的最细粒度对象，适合统一管理图层状态和显示规则。

**`Example`**

```ts
import { MxCpp, McDbLayerTableRecord, McCmColor, McDb } from "mxcad";

// 创建并配置图层记录。
async function testLayerRecord() {
  const mxcad = MxCpp.getCurrentMxCAD();
  // 构造新图层表记录对象
  const layer = new McDbLayerTableRecord()
  // 设置图层颜色
  layer.color = new McCmColor(0, 0, 0)
  // 设置图层是否被冻结
  layer.isFrozen = true
  // 设置图层是否被锁定
  layer.isLocked = true
  // 设置图层是否被关闭
  layer.isOff = true
  // 设置图层线宽
  layer.lineWeight = McDb.LineWeight.kLnWt018
  // 设置图层名
  layer.name = "图层名称"
  // 获取当前图层表
  const layerTable = mxcad.getDatabase().getLayerTable();
  // 向图表中添加图层
  const objId = layerTable.add(layer)
}
```
