# Class: MxCADPluginBase

[2d](../modules/2d.md).MxCADPluginBase

MxCADPluginBase 表示插件的基础配置结构。

**`Description`**

该类封装插件注册与初始化时所需的基础配置项，包括插件注册数据、宿主 UI 接口、
默认打开文件和地图对齐配置，以及示例代码列表。
它通常用于插件初始化前的参数构造和宿主注册数据传递。
使用方法总结：
1. 构造 `MxCADPluginBase` 实例；
2. 填写 `sRegistData`、`mxcadui`、`openFile`、`map_default_data` 等字段；
3. 将此对象传递给宿主的 `MxCADUI.init(plugin)` 方法完成插件初始化。
