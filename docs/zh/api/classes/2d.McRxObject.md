# Class: McRxObject

[2d](../modules/2d.md).McRxObject

McRxObject 是 MxCAD 中所有 Rx 对象的基础基类，负责承接底层 C++/原生对象与 TypeScript 侧的桥接。

**`Description`**

该类用于封装底层对象的通用能力，并为各类 CAD 对象提供统一的访问入口。
通过它可以完成：
- 获取底层实现对象（imp）；
- 读取/设置对象的 JSON 数据；
- 判断对象是否为空或属于某个类型；
- 作为其他实体对象的父类，为派生类统一管理生命周期和对象引用。

使用方式：
1. 通过具体子类继承此类，持有底层原生对象实例；
2. 调用 getImp()、getJson()、setJson()、isKindOf() 等方法访问公共能力；
3. 在需要时配合子类对象继续进行更细粒度的 CAD 数据操作。

总结：在实际开发中，McRxObject 通常不直接用于业务绘制，而是作为底层对象的统一抽象层，供各类 CAD 对象继承和扩展，简化对象生命周期管理和通用能力访问。
