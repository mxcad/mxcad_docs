# Class: McDbDimStyleTableRecord

[2d](../modules/2d.md).McDbDimStyleTableRecord

McDbDimStyleTableRecord 是标注样式表中的单条记录，负责保存和管理尺寸标注样式参数。

**`Description`**

该类用于描述一套尺寸标注样式，包括文字、箭头、尺寸线和单位相关参数。
通过它可以完成：
- 读取和设置标注样式名称；
- 修改尺寸变量的 int / double / string / ObjectId 属性；
- 配置块引用样式（Dimblk、Dimblk1、Dimblk2 等）；
- 作为标注样式表中的记录对象参与尺寸样式管理。

使用方式：
1. 创建 McDbDimStyleTableRecord 实例；
2. 调用 getDimVar* / setDimVar* 设置样式参数；
3. 将该记录添加到标注样式表中；
4. 应用到具体的标注对象中。

具体样式参数的设置可参考 `McObject.addDimStyle` 中的注释说明，`addDimStyle` 最终也是按 DIM 系统变量分组写入：
- double 型参数：如 dimscale、dimtxt、dimasz、dimexo、dimexe、dimrnd、dimdli 等；
- int 型参数：如 dimadec、dimalt、dimclrd、dimclre、dimclrt、dimfit、dimjust、dimtol、dimzin 等；
- string 型参数：如 dimpost、dimapost；
- ObjectId 型参数：如 dimtxsty、dimblk、dimblk1、dimblk2、dimldrblk；

也就是说，`McDbDimStyleTableRecord` 中的 `setDimVarDouble(type, value)`、`setDimVarInt(type, value)`、
`setDimVarString(type, value)` 和 `setDimVarObjectId(type, value)` 与 `addDimStyle(pszName, pszDoubleData, pszIntData, pszStringData, pszIdData)`
中的参数分组完全对应。调用时可直接使用注释里列出的系统变量编号和含义。

例如：
- `setDimVarDouble(40, 200)` 等价于设置 `dimscale = 200`；
- `setDimVarDouble(41, 0.18)` 等价于设置 `dimasz = 0.18`；
- `setDimVarInt(77, 1)` 等价于设置 `dimtol = 1`；
- `setDimVarInt(271, 3)` 等价于设置 `dimdec = 3`；
- `setDimVarString(3, "%%c<>")` 等价于设置 `dimpost = "%%c<>"`；
- `setDimVarObjectId(340, textId)` 等价于设置 `dimtxsty = textId`。

总结：在实际开发中，McDbDimStyleTableRecord 是尺寸风格统一管理的核心对象，适合控制尺寸样式、箭头和文本参数。

**`Example`**

```ts
import { MxCpp, McDbDimStyleTableRecord } from "mxcad";

// 创建并设置尺寸标注样式记录。
async function testDimStyleRecord() {
  const mxcad = MxCpp.getCurrentMxCAD();
  const table = mxcad.getDatabase().getDimStyleTable();
  const rec = new McDbDimStyleTableRecord();
  rec.name = "MyDimStyle";
  rec.setDimVarDouble(40, 200);   // dimscale
  rec.setDimVarDouble(41, 0.18);  // dimasz
  rec.setDimVarInt(77, 1);        // dimtol
  rec.setDimVarInt(271, 3);       // dimdec
  rec.setDimVarString(3, "%%c<>"); // dimpost
  table.add(rec);
}
```
