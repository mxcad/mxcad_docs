# Class: McCmColor

[2d](../modules/2d.md).McCmColor

McCmColor 是 CAD 中的颜色对象，用于统一表示颜色值和颜色索引，并为实体属性设置提供基础颜色数据。

**`Description`**

该类用于处理图形对象的颜色管理，既可以通过 RGB 值设置真实颜色，也可以通过颜色索引控制随层、随块等颜色模式。
通过它可以完成：
- 创建和复制颜色对象；
- 设置 `RGB` 或颜色索引；
- 读取颜色字符串/样式；
- 将颜色应用到实体对象的 `trueColor` 或 `colorIndex` 属性。

使用方式：
1. 构造 McCmColor 实例；
2. 通过 `setRGB()` 或 `colorIndex` 赋值；
3. 将对象赋给实体的颜色属性；
4. 在需要时读取颜色字符串、样式或对象颜色值。

总结：在实际开发中，McCmColor 是实体颜色控制的基础类型，适用于图层颜色、对象颜色和界面颜色展示等场景。

**`Example`**

```ts
import { McCmColor, McDbEntity } from "mxcad";

// 创建颜色对象并将其应用到实体颜色上。
async function testColor() {
  const ent = new McDbEntity();
  ent.trueColor = new McCmColor(255, 0, 0);

  const color = new McCmColor();
  color.setRGB(0, 255, 0);
  console.log("颜色字符串:", color.getColorString());
}
```
