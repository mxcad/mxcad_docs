# Class: McDbAttributeDefinition

[2d](../modules/2d.md).McDbAttributeDefinition

表示块属性定义实体，用于在块定义中定义属性标签和默认文字。

**`Description`**

McDbAttributeDefinition 是一种用于图块定义的文本属性实体，支持设置标签、显示文本、位置、对齐和可见性。
它通常随块定义一起保存，块插入后可提示用户输入属性值，并在图形中显示该属性文本。
使用方法:
1. 创建 `McDbAttributeDefinition` 实例并设置 `tag`、`textString`、`position` 等属性。
2. 将属性定义追加到块定义对象中。
3. 插入块参照后，系统会根据定义提示用户填写属性值并显示属性文本。

**`Example`**

```ts
import { McDbAttributeDefinition, McGePoint3d, McCmColor, McDbBlockTableRecord, McDbBlockReference, MxCpp } from "mxcad";

const blockRecord = new McDbBlockTableRecord();
blockRecord.name = "TEST_BLOCK";
blockRecord.origin = new McGePoint3d(0, 0, 0);

const attribDef = new McDbAttributeDefinition();
attribDef.tag = "MY_TAG";
attribDef.textString = "默认属性值";
attribDef.position = new McGePoint3d(10, 10, 0);
attribDef.alignmentPoint = new McGePoint3d(10, 10, 0);
attribDef.height = 12;
attribDef.widthFactor = 1;
attribDef.trueColor = new McCmColor(255, 0, 0);
attribDef.isInvisible = false;

blockRecord.appendAcDbEntity(attribDef);

const blockRef = new McDbBlockReference();
blockRef.blockTableRecordId = blockRecord.objectId;
blockRef.position = new McGePoint3d(0, 0, 0);
MxCpp.getCurrentMxCAD().drawEntity(blockRef);
```
