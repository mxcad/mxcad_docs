# Class: McDbRasterImageDef

[2d](../modules/2d.md).McDbRasterImageDef

McDbRasterImageDef 是光栅图像定义对象，用于描述 CAD 中的图片资源定义和图像文件路径。

**`Description`**

该类用于管理光栅图像的来源文件、图像数据以及图像存储方式。
通过它可以完成：
- 绑定和读取光栅图像文件路径；
- 保存图像为 Base64 数据；
- 作为图像定义对象提供给 CAD 的图像实体使用。

使用方式：
1. 创建 McDbRasterImageDef 实例；
2. 设置 sourceFileName；
3. 通过 saveToBase64() 生成可传输的图片数据；
4. 进一步用于图像实体显示和图纸集成。

总结：在实际开发中，McDbRasterImageDef 是光栅图像资源的定义层，适用于嵌入、显示和传输图像数据。

**`Example`**

```ts
import { McDbRasterImageDef } from "mxcad";

// 创建并配置栅格图像定义对象。
async function testRasterImageDef() {
  const imageDef = new McDbRasterImageDef();
  imageDef.sourceFileName = "https://cdn.pixabay.com/photo/2022/11/15/12/23/winter-7593872_960_720.jpg";
  const base64 = imageDef.saveToBase64(imageDef.sourceFileName);
  console.log("保存 Base64 成功:", base64);
}
```
