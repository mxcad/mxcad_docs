# Class: MxCADBaseCustomElement

[2d](../modules/2d.md).MxCADBaseCustomElement

表示一个自定义文本元素基类，用于定义文本渲染的计算和绘制逻辑。

**`Description`**

MxCADBaseCustomElement 是所有自定义文本元素的抽象基类，它定义了元素类型、布局计算和绘制结果的契约。
自定义文本元素可以通过 calculate 方法计算排版数据，通过 render 方法生成最终的实体列表并绘制到世界坐标中。
使用方法:
1. 继承 MxCADBaseCustomElement 并实现 type、calculate、render 三个抽象成员。
2. 在 calculate 中基于传入的文本元素和编辑器元素计算宽高、行信息等布局数据。
3. 在 render 中生成实体数组、位置、大小与行高，并返回 RenderResult。
