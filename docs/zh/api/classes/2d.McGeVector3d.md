# Class: McGeVector3d

[2d](../modules/2d.md).McGeVector3d

McGeVector3d 表示三维空间中的方向向量对象。

**`Description`**

该类用于描述和计算向量关系，常见场景包括：
计算两个向量夹角、做点积和叉积、归一化、旋转，以及参与矩阵变换。
它在 CAD 几何运算、方向判断和空间变换中非常常用。

**`Example`**

```ts
import { McGeVector3d } from "mxcad";

const vec1 = new McGeVector3d(10, 0, 0);
const vec2 = new McGeVector3d(0, 10, 0);

const angle = vec1.angleTo2(vec2, McGeVector3d.kZAxis);
const dot = vec1.dotProduct(vec2);
const cross = vec1.crossProduct(vec2);

console.log("夹角：", angle);
console.log("点积：", dot);
console.log("叉积：", cross);
```

### dotProduct

▸ **dotProduct**(`vec`): `number`

两向量的点积。

点积可以判断两个方向的相似程度：
- 结果为 0：两个向量垂直；
- 结果大于 0：两向量方向基本一致；
- 结果小于 0：两向量方向相反。

它常用于判断向量是否垂直、判断投影方向、计算夹角余弦等几何场景。

#### Parameters

| Name | Type | Description |
| :------ | :------ | :------ |
| `vec` | [`McGeVector3d`](2d.McGeVector3d.md) | 三维向量对象 |

#### Returns

`number`

点积结果

**`Example`**

```ts
import { McGeVector3d } from "mxcad";

// 方向向量：沿 X 轴正方向
const v1 = new McGeVector3d(10, 0, 0);

// 方向向量：沿 Y 轴正方向
const v2 = new McGeVector3d(0, 10, 0);

// 点积为 0，说明两个方向垂直
const dot = v1.dotProduct(v2);
console.log("dot:", dot); // 0

// 继续判断一个向量是否和 X 轴同向
const v3 = new McGeVector3d(5, 0, 0);
const sameDir = v1.dotProduct(v3) > 0;
console.log("同向：", sameDir); // true
```
