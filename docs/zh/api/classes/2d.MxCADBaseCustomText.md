# Class: MxCADBaseCustomText

[2d](../modules/2d.md).MxCADBaseCustomText

表示自定义文本元素的基类，用于定义文本节点的布局计算和实体生成。

**`Description`**

MxCADBaseCustomText 是一个抽象基类，负责为自定义文本节点提供宽高计算和实体创建接口。
继承此类的实现类可以根据文本节点内容计算尺寸，并生成对应的 McDbEntity 或 McDbCustomEntity 实体。
使用方法:
1. 继承 MxCADBaseCustomText 并实现 type、calculate、create 方法。
2. 在 calculate 中根据文本节点计算宽度和高度等布局数据。
3. 在 create 中根据计算结果和位置生成可绘制实体数组。
