# Class: McDbGroup

[2d](../modules/2d.md).McDbGroup

McDbGroup 是图纸中的分组对象，用于把多个对象组织成一个逻辑集合。

**`Description`**

该类用于管理一组对象的整体选择、命名和描述信息，便于对多个对象进行统一处理。
通过它可以完成：
- 创建一组对象集合；
- 设置组名和描述；
- 控制组是否可选；
- 通过数据库中的组字典保存和查询分组。

使用方式：
1. 先选择多个对象；
2. 调用数据库的 CreateGroup() 创建组；
3. 通过 name、description、isSelectable 控制组属性；
4. 后续按组对象执行整体管理或选择处理。

总结：在实际开发中，McDbGroup 是对象分组管理的核心类型，适合实现批量处理、统一选择和组织管理。

**`Example`**

```ts
import { MxCpp, McDbGroup, MxCADSelectionSet } from "mxcad";

// 创建并管理图形分组对象。
async function testGroup() {
  const ss = new MxCADSelectionSet();
  const ok = await ss.userSelect("选择要分组的对象");
  if (!ok) return;

  const mxcad = MxCpp.getCurrentMxCAD();
  const group = new McDbGroup();
  group.name = "MyGroup";
  group.description = "测试分组";
  mxcad.getDatabase().CreateGroup(ss.getIds(), group.name);
}
```
