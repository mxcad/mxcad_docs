# Class: McGeMatrix3d

[2d](../modules/2d.md).McGeMatrix3d

McGeMatrix3d 表示三维空间中的变换矩阵对象。

**`Description`**

该类用于构造和应用平移、旋转、缩放、镜像等几何变换矩阵，
可用于点、向量、实体对象的空间变换。它是实现 CAD 图形变换和坐标系转换的核心类型之一。

**`Example`**

```ts
import { McGeMatrix3d, McGePoint3d, McGeVector3d } from "mxcad";

const matrix = new McGeMatrix3d();
matrix.setToTranslation(new McGeVector3d(20, 10, 0));//平移矩阵

const pt = new McGePoint3d(1, 2, 0);
pt.transformBy(matrix);//应用平移矩阵

console.log(pt.x, pt.y, pt.z);
```

| Name | Type | Description |
| :------ | :------ | :------ |
| `angle` | `number` | 旋转角度。 |
| `axis` | [`McGeVector3d`](2d.McGeVector3d.md) | 旋转轴向量。 |
| `center` | [`McGePoint3d`](2d.McGePoint3d.md) | 旋转中心点。 |

#### Returns

[`McGeMatrix3d`](2d.McGeMatrix3d.md)

```ts

 event.transformBy(matrix);
```
