# Class: McDbDatabase

[2d](../modules/2d.md).McDbDatabase

McDbDatabase 是 CAD 图纸数据库对象，承载图纸中所有数据和对象信息的总入口。

**`Description`**

该类表示当前图纸的数据库容器，保存着层表、线型表、文字样式表、块表、字典等核心数据结构。
通过它可以完成：
- 获取和管理图层、线型、样式、块表等表对象；
- 设置当前图层、当前颜色、当前文字样式和当前线型；
- 读写文件、插入块、创建组、处理命名对象字典；
- 对当前数据库的修改状态进行查询和重置。

使用方式：
1. 通过 MxCpp.getCurrentMxCAD().getDatabase() 获取数据库实例；
2. 调用 getLayerTable()、getBlockTable()、getTextStyleTable() 等方法访问各类表；
3. 使用 setCurrentlyLayerName()、setCurrentlyTrueColor()、setCurrentlyTextStyle() 等设置当前绘图状态；
4. 根据需要访问命名对象字典、创建组或保存/读取图纸文件。

总结：在实际开发中，McDbDatabase 是整个图纸数据的总入口，几乎所有图层、块、样式、字典和对象管理都需要从它开始。

**`Example`**

```ts
import { MxCpp, McDbDatabase } from "mxcad";

// 获取当前数据库并进行基本操作。
async function testDatabase() {
  const mxcad = MxCpp.getCurrentMxCAD();
  const database: McDbDatabase = mxcad.getDatabase();

  const layerTable = database.getLayerTable();
  console.log("图层表对象:", layerTable);

  const blockTable = database.getBlockTable();
  console.log("块表对象:", blockTable);

  database.setCurrentlyLayerName("0");
  console.log("当前图层:", database.getCurrentlyLayerName());
}
```

```ts
  import { MxCADUiPrEntity, MxCpp } from "mxcad";
  //隐藏目标对象所在图层
  async function Mx_SelectEntitHideLayer() {
     let selEntity1 = new MxCADUiPrEntity();

     selEntity1.setMessage("选择要隐藏的对象")
     let id = await selEntity1.go();
     if (!id.isValid()) return;

     let ent = id.getMcDbEntity();
     let mxcad = MxCpp.getCurrentMxCAD();
     let layerTable = mxcad.getDatabase().getLayerTable();
     let layerId = layerTable.get(ent.layer);
     let layerRec = layerId.getMcDbLayerTableRecord();
     if (layerRec === null) return;
     layerRec.isOff = true;
     mxcad.updateLayerDisplayStatus();
     mxcad.updateDisplay()
   }
```
