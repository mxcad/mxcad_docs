# Class: MxCADResbuf

[2d](../modules/2d.md).MxCADResbuf

MxCADResbuf 是一个用于构造和读取 CAD 规则数据的容器类。

**`Description`**

该类用于封装 AutoCAD / MxCAD 中的 resbuf 数据结构，常见于实体筛选、图层条件、扩展数据查询和对象选择等场景。
它本质上更接近“数据规则集/条件容器”，用于把多种查询条件组织成统一的数据格式，再传递给选择集、命令交互、对象查询等功能；同时也能读取字符串、数值、点、对象 ID 等数据。
使用方法：
1. new MxCADResbuf() 创建条件容器；
2. 调用 AddMcDbEntityTypes / AddString / AddPoint 等方法添加规则项；
3. 将该容器传递给 MxCADSelectionSet.allSelect()、MxCADUtility.findEntAtPoint() 等接口；
4. 使用 AtString / AtPoint / AtDouble / GetCount 等方法读取其中的数据。

**`Example`**

```ts
import { MxCADResbuf, MxCADSelectionSet } from "mxcad";

// 创建条件容器，仅筛选直线和圆
const rules = new MxCADResbuf();
rules.AddMcDbEntityTypes("LINE,CIRCLE");

const ss = new MxCADSelectionSet();
ss.allSelect(rules);
console.log("当前选择集对象数量：", ss.count());
```

```ts
import { MxCADResbuf, DxfCode, MxCADSelectionSet } from "mxcad"

let ss = new MxCADSelectionSet();
// 定义筛选条件，限定实体类型：直线，圆弧，圆，多段线
const filter1 = new MxCADResbuf([DxfCode.kEntityType, "LINE,ARC,CIRCLE,LWPOLYLINE"]));

  const filter2 = new MxCADResbuf([DxfCode.kEntityType, "LINE,ARC,CIRCLE,LWPOLYLINE", DxfCode.kLayer, "0"]);

```

### forEach

▸ **forEach**(`call`): `void`

遍历数据。

#### Parameters

| Name | Type | Description |
| :------ | :------ | :------ |
| `call` | (`val`: `any`, `type`: `number`, `dxf`: `number`, `index`: `number`) => `void` | 接受3个参数的回调函数（val:元素的值，type:元素类型，dxf:元素的数据交换格式） |

#### Returns

`void`

**`Example`**

```ts
  import {MxCADResbuf} from "mxcad"

  //创建MxCADResbuf实例
  const cadResbuf = new MxCADResbuf();
  cadResbuf.AddPoint(new McGePoint3d(1,2,3));//添加一个point元素
  cadResbuf.AddString(“Hello”);//添加一个字符串元素
  cadResbuf.AddDouble (3.14);//添加双精度型数据
  cadResbuf.AddLong (42);//添加一个整型数据

  //迭代CAD Resbuf实例中的元素
  cadResbuf.forEach((val, type, dxf)=>{
   console.log("值:",val);
   console.log("类型:",type);
   console.log("DXF:",DXF);
   });
   //输出:
   //值:{x: 1, y: 2, z: 3}
   //类型:5009
   // dxf: 10
   //值:Hello
   //类型:5005
   // dxf: 10
   //取值:3.14
   //类型:5001
   // dxf: 10
   //取值:42
   //类型:5010
   // dxf: 10
```
