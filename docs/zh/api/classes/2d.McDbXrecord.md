# Class: McDbXrecord

[2d](../modules/2d.md).McDbXrecord

McDbXrecord 是扩展记录对象，用于为实体或字典附加自定义扩展数据。

**`Description`**

该类用于存放附加信息，能够把 resbuf 数据挂接到对象上，以保存更多业务参数和自定义字段。
通过它可以完成：
- 设置扩展记录数据；
- 读取扩展记录数据；
- 将自定义属性写入实体或字典对象；
- 在对象中保留业务场景所需的附加信息。

使用方式：
1. 创建 McDbXrecord 实例；
2. 使用 MxCADResbuf 组装数据；
3. 调用 setData() 写入；
4. 通过 getData() 读取扩展信息。

总结：在实际开发中，McDbXrecord 是图纸对象附加自定义数据的标准方式，适合存储业务属性和扩展信息。

**`Example`**

```ts
import { MxCpp, McDbDictionary, McDbXrecord, MxCADResbuf } from "mxcad";

// 创建并操作扩展记录 Xrecord。
async function testXrecord() {
  const mxcad = MxCpp.getCurrentMxCAD();
  const dict = mxcad.getDatabase().getNamedObjectsDictionary();
  const xrec = new McDbXrecord();
  const data = new MxCADResbuf();
  data.AddString("demo");
  xrec.setData(data);
  dict.addObject("MyRecord", xrec);
}
```
