# Class: MxCADUiPrBase

[2d](../modules/2d.md).MxCADUiPrBase

交互取点基类，封装用户交互输入的通用功能。

**`Description`**

`MxCADUiPrBase` 是所有 `MxCADUiPr*` 系列交互类的抽象基础，封装了与用户交互取点、关键字输入、
动态绘制、提示信息、捕捉设置等常用行为。子类通常通过传入不同的内部实现（如 `MrxDbgUiPrPoint`、
`MrxDbgUiPrDist` 等）来实现具体的交互语义，但共享如下能力：
- 设置/获取提示消息（`setMessage` / `message`）
- 管理关键字列表与检测用户选择（`setKeyWords` / `keyWordPicked` / `isKeyWordPicked`）
- 设置动态绘制回调以在交互过程中绘制临时图形（`setUserDraw`）
- 获取交互结果的详细退出原因与类型（`getDetailedResult` / `getStatus` / `getResultPointType`）
- 控制动态输入、极轴/格网/捕捉等跟踪行为（`setDisableDynInput` / `setDisablePolarAxisTrace` 等）

使用方法:
1. 直接使用已有子类（如 `MxCADUiPrPoint`、`MxCADUiPrDist` 等）完成具体取点/取距操作；
2. 或通过继承 `MxCADUiPrBase` 并传入自定义内部实现（imp）来实现新的交互控件；
3. 在交互前设置提示、关键字、动态绘制回调等，调用子类的 `go()` 方法获取用户输入。

**`Example`**

```ts
import { MxCADUiPrPoint } from 'mxcad';

async function example() {
  const getPoint = new MxCADUiPrPoint();
  getPoint.setMessage('\n指定第一个点:');
  getPoint.setUserDraw((pt, worldDraw) => {
    // 在动态绘制回调中绘制临时标记
    worldDraw.drawCircle(pt.toVector3(), 10);
  });
  const pt = await getPoint.go();
  if (!pt) return;
}
```

### setDynamicInputType

▸ **setDynamicInputType**(`type`): `void`

设置动态输入类型

#### Parameters

| Name | Type | Description |
| :------ | :------ | :------ |
| `type` | `DynamicInputType` | 动态输入显示类型 |

#### Returns

`void`

**`Example`**

```ts
//以 MxCADUiPrPoint 类示例
  import { MxCADUiPrPoint } from 'mxcad';
  import { DynamicInputType } from "mxdraw";

  async function Mx_WindowZoom() {
    let getPoint = new MxCADUiPrPointTransform(MxInsidePublicFuns.getMxCADViewSpinMatrix(MxCpp.getCurrentMxCAD()));
    getPoint.disableAllTrace();
    getPoint.setMessage("\n点取缩放区域");
    getPoint.setDynamicInputType(DynamicInputType.kDynTip);
    let pt1 = await getPoint.go();
    if (pt1 == null) return;
    let mxcad = MxCpp.getCurrentMxCAD();
    getPoint.setUserDraw((p1, worldDraw) => {
        worldDraw.drawRect(MxCoordConvert.cad2doc1((pt1 as any)), MxCoordConvert.cad2doc1((p1 as any)));
    });

    let pt2 = await getPoint.go();
    if (pt2 == null) return;

    pt1.transformBy(getPoint.rmat);
    pt2.transformBy(getPoint.rmat);
    mxcad.zoomW(pt1, pt2);
 }
```

            pl.isClosed = true;
            pWorldDraw.drawMcDbEntity(pl);
        });

        if (!await getNextPt.go()) return;

        getNextPt.drawReserve();
    }
