# Class: McDbXrecord

[2d](../modules/2d.md).McDbXrecord

McDbXrecord is an extended record object used to attach custom extended data to entities or dictionaries.

**`Description`**

This class is used to store additional information and can attach respuff data to objects to save more business parameters and custom fields.
It can accomplish:
-Set up extended record data;
-Read extended record data;
-Write custom attributes into entity or dictionary objects;
-Retain additional information required for the business scenario in the object.

Usage:
1. Create an instance of McDbXrecord;
2. Assemble data using MxCADResbuf;
3. Call setData() to write;
4. Read extended information through getData().

Summary: In practical development, McDbXrecord is a standard way to attach custom data to drawing objects, suitable for storing business attributes and extended information.

**`Example`**

```ts
import { MxCpp, McDbDictionary, McDbXrecord, MxCADResbuf } from "mxcad";

//Create and operate the extended record Xrecord.
async function testXrecord() {
  const mxcad = MxCpp.getCurrentMxCAD();
  const dict = mxcad.getDatabase().getNamedObjectsDictionary();
  const xrec = new McDbXrecord();
  const data = new MxCADResbuf();
  data.AddString("demo");
  xrec.setData(data);
  dict.addObject("MyRecord", xrec);
}
```
