# Class: MxCADPluginBase

[2d](../modules/2d.md).MxCADPluginBase

MxCADPluginBase represents the basic configuration structure of the plugin.

**`Description`**

This class encapsulates the basic configuration items required for plugin registration and initialization, including plugin registration data, host UI interface
Default file and map alignment configuration, as well as sample code list.
It is usually used for parameter construction and host registration data transfer before plugin initialization.
Summary of usage:
1. Construct an instance of 'MxCADPluginBase';
2. Fill in fields such as' sRegistData ',' mxcadui ',' openFile ',' map_default_data ', etc;
3. Pass this object to the host's' MxCADUI. init (plugin) 'method to complete plugin initialization.
