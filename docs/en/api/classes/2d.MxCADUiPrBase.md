# Class: MxCADUiPrBase

[2d](../modules/2d.md).MxCADUiPrBase

Interaction based classes encapsulate the general functionality of user interaction input.

**`Description`**

`MxCADUiPrBase is the abstract foundation of all MxCADUiPr * series interaction classes, encapsulating user interaction point taking, keyword input
Common behaviors such as dynamic drawing, prompt information, and capture settings. Subclasses are usually implemented by passing in different internal implementations (such as' MrxDBgUiPrPoint '
`MrxDBgUiPrList, etc.) to implement specific interactive semantics, but share the following capabilities:
-Set/Get Prompt Messages (` setMessage `/` message `)
-Manage keyword list and detect user selection (` setKeyWords `/` keyWordPicked `/` isKeyWordPicked `)
-Set dynamic drawing callback to draw temporary graphics during interaction (` setUserDraw `)
-Get detailed exit reasons and types of interaction results (` getDetailedResult `/` getStatus `/` getResultPointType `)
-Control dynamic input, polar/grid/snap tracking behavior (setDisabDynInput/setDisabPolarAxisTrack, etc.)

Instructions:
1. Directly use existing subclasses (such as' MxCADUiPrPoint ',' MxCADUiPrList ', etc.) to complete specific point/distance operations;
2. Alternatively, new interactive controls can be implemented by inheriting 'MxCADUiPrBase' and passing in a custom internal implementation (imp);
3. Set prompts, keywords, dynamic drawing callbacks, etc. before interaction, and call the ` go() ` method of the subclass to obtain user input.

**`Example`**

```ts
import { MxCADUiPrPoint } from 'mxcad';

async function example() {
  const getPoint = new MxCADUiPrPoint();
GetPoint.setMessage (specify the first point: ');
  getPoint.setUserDraw((pt, worldDraw) => {
//Draw temporary markers in dynamic drawing callbacks
    worldDraw.drawCircle(pt.toVector3(), 10);
  });
  const pt = await getPoint.go();
  if (!pt) return;
}
```

```ts
//Example of MxCADUiPrPoint class
  import { MxCADUiPrPoint } from 'mxcad';
  import { DynamicInputType } from "mxdraw";

  async function Mx_WindowZoom() {
    let getPoint = new MxCADUiPrPointTransform(MxInsidePublicFuns.getMxCADViewSpinMatrix(MxCpp.getCurrentMxCAD()));
    getPoint.disableAllTrace();
GetPoint.setMessage ("\ n Click to zoom area");

    });

    let pt2 = await getPoint.go();
    if (pt2 == null) return;

    pt1.transformBy(getPoint.rmat);
    pt2.transformBy(getPoint.rmat);
    mxcad.zoomW(pt1, pt2);
 }
```
