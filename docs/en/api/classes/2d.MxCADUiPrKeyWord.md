# Class: MxCADUiPrKeyWord

[2d](../modules/2d.md).MxCADUiPrKeyWord

MxCADUiPrKeyWord is a prompt class used for interactive input of keyword options.

**`Description`**

This class is used to allow users to select an option from a set of keywords, such as "add/modify/delete", "automatic/manual", "yes/no", etc.
Commonly used for command branch selection and interactive parameter confirmation, suitable for simplifying the user decision-making process of complex commands.
Usage:
1. Create a keyword input tool using new MxCADUiPrKeyWord();
2. Call setKeyWords() to set the keyword list;
3. Call go() and wait for the user to select;
4. After obtaining the return value, use value() or keyWordPicked() to continue with the next logical step.

**`Example`**

```ts
import { MxCADUiPrKeyWord } from "mxcad";

const getKey = new MxCADUiPrKeyWord();
GetKey.setMessage ("Please choose the operation method");
GetKey. setKeyWords ("[Manual (M)/Automatic (A)]");
const key = await getKey.go();
if (!key) return;

Console.log ("user selection:", key);
```

  import { MxCADUiPrPoint } from 'mxcad';
