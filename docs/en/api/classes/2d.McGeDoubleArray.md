# Class: McGeDoubleArray

[2d](../modules/2d.md).McGeDoubleArray

McGeDoubleArray represents an array container of double precision floating-point numbers.

**`Description`**

This class is used to store and process floating-point sets, commonly used in numerical sampling, coordinate value caching
Transform parameters and other scenarios that require continuous floating-point data.

**`Example`**

```ts
import { McGeDoubleArray } from "mxcad";

const values = new McGeDoubleArray();
values.append(1.2);
values.append(3.4);
values.append(5.6);

console.log(values.at(1)); //Obtain the value of the first index position;
console.log(values.length()); //Obtain the length of the array;
```
