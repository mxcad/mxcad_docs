# Class: McDbLayerTableRecord

[2d](../modules/2d.md).McDbLayerTableRecord

McDbLayerTableRecord is a single record in a layer table used to save and manage the properties of layers.

**`Description`**

This class is used to describe a layer, including layer name, color, line type, locked state, frozen state, and whether it is turned off or not.
It can accomplish:
-Create and name layers;
-Set layer color, line width, line type, and printability;
-Control whether layers are frozen, locked, or closed;
-Add layer objects to the layer table and use them for subsequent entity assignment.

Usage:
1. Create an instance of McDbLayerTableRecord;
2. Set properties such as name/color/lineWeight/isLocked;
3. Insert into the layer table;
4. Use its object ID to specify a layer for the entity.

Summary: In practical development, McDbLayerTableRecord is the most fine-grained object for layer attribute control, suitable for unified management of layer states and display rules.

**`Example`**

```ts
import { MxCpp, McDbLayerTableRecord, McCmColor, McDb } from "mxcad";

//Create and configure layer records.
async function testLayerRecord() {
  const mxcad = MxCpp.getCurrentMxCAD();
//Construct a new layer table to record objects
  const layer = new McDbLayerTableRecord()
//Set layer color
  layer.color = new McCmColor(0, 0, 0)
//Set whether the layer is frozen
  layer.isFrozen = true
//Set whether the layer is locked
  layer.isLocked = true
//Set whether the layer is turned off
  layer.isOff = true
//Set layer line width
  layer.lineWeight = McDb.LineWeight.kLnWt018
//Set layer name
Layer.name="Layer Name"
//Retrieve the current layer table
  const layerTable = mxcad.getDatabase().getLayerTable();
//Add layers to the chart
  const objId = layerTable.add(layer)
}
```
