# Class: McDbRasterImageDef

[2d](../modules/2d.md).McDbRasterImageDef

McDbRasterImageDef is a raster image definition object used to describe image resource definitions and image file paths in CAD.

**`Description`**

This class is used to manage the source files, image data, and image storage methods of raster images.
It can accomplish:
-Bind and read the path of the raster image file;
-Save the image as Base64 data;
-As an image defined object provided to CAD for use as an image entity.

Usage:
1. Create an instance of McDbRasterImageDef;
2. Set sourceFileName;
3. Generate transferable image data using saveToBase64();
4. Further used for image entity display and drawing integration.

Summary: In practical development, McDbRasterImageDef is the definition layer for raster image resources, suitable for embedding, displaying, and transmitting image data.

**`Example`**

```ts
import { McDbRasterImageDef } from "mxcad";

//Create and configure raster image definition objects.
async function testRasterImageDef() {
  const imageDef = new McDbRasterImageDef();
  imageDef.sourceFileName = "https://cdn.pixabay.com/photo/2022/11/15/12/23/winter-7593872_960_720.jpg";
  const base64 = imageDef.saveToBase64(imageDef.sourceFileName);
Console.log ("Saved Base64 successfully:", Base64);
}
```
