# Class: MxCADUiPrInt

[2d](../modules/2d.md).MxCADUiPrInt

MxCADUiPrInt is a prompt class used for interactive input of integers.

**`Description`**

This class is used to allow users to input integer parameters in the command flow, such as layer number, quantity, repetition count, index value, etc.
Commonly used for command prompts and interactive parameter input, suitable for scenarios where users need to confirm numerical parameters.
Usage:
1. Create an integer input using new MxCADUiPrInt();
2. Call setMessage () to set prompt text;
3. Wait for the user to input an integer through go();
After obtaining the return value, use value() to continue the subsequent logic.

**`Example`**

```ts
import { MxCADUiPrInt } from "mxcad";

const getInt = new MxCADUiPrInt();
GetInt.setMessage ("Please enter the number of loops:");
const count = await getInt.go();
if (count == null) return;

Console.log ("number of loops:", count);
```

//Example of MxCADUiPrPoint class
  import { MxCADUiPrPoint } from 'mxcad';
  import { DynamicInputType } from "mxdraw";

  async function Mx_WindowZoom() {

    pt2.transformBy(getPoint.rmat);
    mxcad.zoomW(pt1, pt2);
 }
