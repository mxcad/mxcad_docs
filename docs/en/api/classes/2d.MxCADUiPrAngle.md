# Class: MxCADUiPrAngle

[2d](../modules/2d.md).MxCADUiPrAngle

MxCADUiPrAngle is a prompt class used for interactive input of angle values.

**`Description`**

This class is used to allow users to determine the angle based on two reference directions or specified positions in the drawing, and return the angle value.
In CAD commands, it is commonly used for interactive scenes such as rotation angle, angle, direction angle, and parameter settings.
Usage:
1. Create an angle input device using new MxCADUiPrAngle();
2. Call setMessage () to set prompt information;
3. Use go() to allow users to specify angles;
After obtaining the return value, use the angle result through value() for subsequent calculations.

**`Example`**

```ts
import { MxCADUiPrAngle } from "mxcad";

const getAngle = new MxCADUiPrAngle();
GetAngle.setMessage ("Please select reference direction and enter angle");
const angle = await getAngle.go();
if (angle == null) return;

Console.log ("angle value:", angle);
```

//Example of MxCADUiPrPoint class
  import { MxCADUiPrPoint } from 'mxcad';
  import { DynamicInputType } from "mxdraw";

  async function Mx_WindowZoom() {
    let getPoint = new MxCADUiPrPointTransform(MxInsidePublicFuns.getMxCADViewSpinMatrix(MxCpp.getCurrentMxCAD()));

    pt2.transformBy(getPoint.rmat);
    mxcad.zoomW(pt1, pt2);
 }
