# Class: McDbAttribute

[2d](../modules/2d.md).McDbAttribute

McDbAttribute is an attribute entity class used to represent block attribute objects.

**`Description`**

This class is used to handle the attribute content in block references and is commonly used for reading, modifying, and managing attribute values.

Summary of usage:
1. First, create or retrieve the McDbAttribute object.
2. Set attribute labels, attribute values, visibility, and other attributes again.
3. Finally, associate it with the corresponding block definition or block reference.

**`Example`**

```ts 
   import { McDbBlockReference, McDbAttribute, MxCADUiPrEntity, MxCADResbuf, DxfCode } from "mxcad";

//Traverse the attribute text in the block
   async function Mx_Test() {
       const getBlock = new MxCADUiPrEntity();
GetBlock.setMessage ('Select Target Block ');
       getBlock.setFilter(new MxCADResbuf([DxfCode.kEntityType, "INSERT"]));
       const block_id = await getBlock.go();
       if (!block_id.isValid()) return;
       let block = block_id.getMcDbEntity() as McDbBlockReference;

       let blkRef: McDbBlockReference = block;
       let aryId = blkRef.getAllAttribute();
       aryId.forEach((id) => {
           let attribt: McDbAttribute = id.getMcDbEntity() as any;
           console.log(attribt.textString);
           console.log(attribt.tag);
       })
   }
```

      let retExplode: MxCADResbuf = ent.explode();
      if (retExplode.GetCount() == 0) return;
      let iExplodeConut = retExplode.GetCount();
      for (let j = 0; j < iExplodeConut; j++) {
          let tmpobj = retExplode.AtObject(j).val;
          if(tmpobj instanceof McDbEntity ){
              mxcad.drawEntity(tmpobj);
          }
      }
