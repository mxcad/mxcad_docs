# Class: MxCADUiPrEntity

[2d](../modules/2d.md).MxCADUiPrEntity

MxCADUiPrEntity is a prompt class used for interactive selection of entity objects.

**`Description`**

This class is used to allow users to click on an entity on a drawing and return the corresponding object ID. Subsequently, the entity instance can be obtained through McObjectid. getMcDbEntity () for subsequent operations such as editing, deleting, and property reading.
It is suitable for scenarios where users need to continue operating after selecting an object, such as editing objects, attaching properties, batch modifications, etc.
Usage:
1. Create an entity selector using new MxCADUiPrAntity();
2. Call setMessage () to set prompt information and use setFilter () to restrict the available object types;
3. Call go() and wait for the user to select an object;
4. After obtaining the McObject ID, use getMcDbEntity () to read the object and proceed to the next step of processing.

**`Example`**

```ts
import { MxCADUiPrEntity } from "mxcad";

const getEnt = new MxCADUiPrEntity();
GetEnt. setMessage ("Please select target object");
const entId = await getEnt.go();
if (!entId || !entId.id) return;

const ent = entId.getMcDbEntity();
If (ent) console. log ("Current object type:", ent. objectName);
```

**`Example`**

```ts
//Example of MxCADUiPrPoint class
  import { MxCADUiPrPoint } from 'mxcad';
  import { DynamicInputType } from "mxdraw";

  async function Mx_WindowZoom() {
    let getPoint = new MxCADUiPrPointTransform(MxInsidePublicFuns.getMxCADViewSpinMatrix(MxCpp.getCurrentMxCAD()));
    getPoint.disableAllTrace();
GetPoint.setMessage ("\ n Click to zoom area");
    getPoint.setDynamicInputType(DynamicInputType.kDynTip);
    let pt1 = await getPoint.go();
    if (pt1 == null) return;
    let mxcad = MxCpp.getCurrentMxCAD();
    getPoint.setUserDraw((p1, worldDraw) => {
        worldDraw.drawRect(MxCoordConvert.cad2doc1((pt1 as any)), MxCoordConvert.cad2doc1((p1 as any)));
    });

    let pt2 = await getPoint.go();
    if (pt2 == null) return;

    pt1.transformBy(getPoint.rmat);
    pt2.transformBy(getPoint.rmat);
    mxcad.zoomW(pt1, pt2);
 }
```
